三个手机网页小工具：

- **单词发音台**（根目录 `index.html`）：查英文单词的美式和英式音标、中文释义并听发音，可离线使用。
- **胶片调色**（`film/index.html`）：上传照片，套用富士胶片模拟、常用胶片配方（Kodachrome 64、Portra 400 等）和网络流行滤镜（日系、港风、奶油色、黑金、森系、赛博朋克、拍立得等），可调强度、清晰度、颗粒、暗角，按原尺寸导出 JPG。照片只在本机处理，不会上传。
- **麻将陪练**（`mahjong/index.html`）：给完全不会打麻将的人用。入门页图解认牌、胡牌规则、出牌流程和听牌；助手页点入手牌，告诉你该打哪张、听哪几张、胡没胡；练习页有“听什么”和“打哪张”两种小测验；小抄页列出开打前要问朋友的规矩和常用术语。
